## What Ilithiyana wants to do

Masande, also known as Sunday, wants to turn Ilithiyana into a more structured and automated online tutoring business. The first major change is to refocus the current website so that it only presents **Ilithiyana Academics**. All references to other unrelated projects, such as **infrastructure** and **fleet management**, should be removed.

The goal is to make the website clearly represent the academic business only, so parents, learners, and tutors immediately understand what Ilithiyana does. Sunday wants the platform to support the full academic workflow, not just act as an information page.

He wants the system to:

- collect learner applications directly on the website instead of through PDF forms and WhatsApp
- automatically capture and store parent and learner information in a database
- reduce manual data entry into Excel sheets
- filter applicants by province, grade, level, subject, and other criteria
- manage class allocation and scheduling more efficiently
- support subscription-based payments for parents
- send payment reminders automatically, preferably by email for now
- keep tutor session records and payroll information in a more automated way
- support future growth toward a more complete online school model

Sunday also wants the business to remain practical and affordable, with solutions that fit a small but growing tutoring operation. He is open to a system that can start simple and expand over time.

## Detailed action items

### 1. Refocus the website on Ilithiyana Academics only

- Remove all pages, navigation items, and content related to infrastructure.
- Remove all pages, navigation items, and content related to fleet management.
- Rework the homepage to clearly position Ilithiyana as an academic tutoring service.
- Update headings, descriptions, and images so they reflect only education and tutoring.
- Ensure the brand messaging is consistent across the website.

### 2. Build an online application workflow

- Replace the current PDF-based application process with a website form.
- Allow parents to complete the application form directly online.
- Capture the learner’s details, parent details, school name, grade, location, subjects, and supporting documents.
- Add fields for the learner’s latest academic report and proof of payment.
- Make the form easy to use on mobile devices.

### 3. Store and organize data in a database

- Save all submitted applications into a central database.
- Create separate records for parents, learners, tutors, subscriptions, applications, and classes.
- Keep data searchable and filterable.
- Reduce the need for manual copying of data into Excel.

### 4. Automate applicant sorting and filtering

- Set up rules to categorize learners by:
  - province
  - grade
  - level
  - subject
  - school
  - region
- Use the captured form data to help place learners into the correct group.
- Make it easier to see which learners belong in which class or subscription path.

### 5. Improve class scheduling

- Create a scheduling system for weekly classes.
- Show learners their class times inside the system.
- Link classes to the correct subject, tutor, grade, and level.
- Reduce the manual creation of Google Meet links and weekly sharing.
- Keep the Google Meet workflow if needed, but make it more automated.

### 6. Support subscription and payment management

- Allow parents to choose a package during application or onboarding.
- Track payment status for each learner.
- Show whether a subscription is paid, pending, or overdue.
- Support recurring subscription logic where possible.
- Review payment gateway options such as PayFast for EFT-based or recurring payments.

### 7. Set up payment reminders

- Send automatic reminder emails when a subscription is due.
- Keep WhatsApp reminders as a manual backup for now if needed.
- Avoid expensive messaging channels unless the business grows enough to justify them.
- Make reminders clear and timely so parents know when to pay.

### 8. Manage tutor sessions and payroll

- Create a tutor timesheet or session log system.
- Allow tutors or the admin to record completed classes by month.
- Auto-calculate tutor pay based on number of sessions and the agreed session rate.
- Let Sunday approve or reject submitted timesheets.
- Keep the process connected to payroll records and financial reporting.

### 9. Improve admin and reporting tools

- Build an admin dashboard for viewing learners, parents, tutors, subscriptions, and applications.
- Add export options to Excel and PDF.
- Make it easy to review totals by subject, grade, province, or tutor.
- Support finance tracking and reporting over time.

### 10. Prepare for long-term growth

- Design the system so it can expand into a fuller online school later.
- Keep the structure flexible for future features like assessments, performance tracking, and richer learner dashboards.
- Plan for future marketing support once the website and operations are stable.

## Summary of Sunday’s main priorities

- Rebrand the website to focus only on Ilithiyana Academics.
- Remove non-academic business references.
- Replace manual PDF and Excel processes with a proper online system.
- Automate applications, filtering, scheduling, payment tracking, and tutor management.
- Keep the solution simple at first, but scalable for the future.
